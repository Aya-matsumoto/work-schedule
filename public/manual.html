OVERVIEW

システム概要

本システムは、橋梁点検業務における複数の業務・橋梁・担当者のスケジュールを ガントチャート形式で一元管理するWebアプリケーションです。

📊 工程の見える化
業務・橋梁ごとの工程を6ヶ月ガントチャートで把握
👥 担当者管理
担当者ごとの3ヶ月稼働状況・空き確認
🔄 自動割り振り
点検完了日・シフトをもとに工程を自動配分
✏️ 柔軟な編集
ドラッグ&ドロップや直接入力で日程調整

対応ブラウザ

Google Chrome / Microsoft Edge（最新版）を推奨します。

アクセス方法

ブラウザのアドレスバーにシステムのURLを入力してアクセスしてください。

担当者稼働担当者ごとの3ヶ月間稼働状況を確認。空き日確認や予定の追加、担当者の絞り込みが可能です。

DASHBOARD

ダッシュボード

アプリを開くと最初に表示される画面です。登録されているすべての業務・橋梁の工程状況を確認できます。

3-1. ガントチャート表示

「ガント」タブが選択されている状態で表示されます。当月から6ヶ月分のガントチャートを横スクロールで確認できます。

ガント画面の構成
要素説明
業務ドロップダウンツールバー左側のドロップダウンで表示する業務を切り替えます。選択した業務の橋梁一覧が表示されます。
橋梁名（左端固定）横スクロール時も橋梁名は左端に固定表示されます。
月・日ヘッダー（上部固定）縦スクロール時も月・日ヘッダーは上部に固定表示されます。
色付きバー工程の期間を表します。色は工程種別ごとに異なります。
🚩フラグ橋梁の点検完了日をガント上に赤いフラグで表示します。
土・日列薄いグレーで強調表示されます。
スクロールバーガント下部に常時表示されます。横スクロールに使用します。

業務の切り替え

ツールバー左側の業務ドロップダウンをクリックすると、登録されている業務の一覧が表示されます。業務を選択すると、その業務に属する橋梁の工程がガントに表示されます。

月の切り替え

「← 前月」「翌月 →」ボタンで表示開始月を変更できます。「今月」ボタンで当月に戻ります。6ヶ月分のガントが表示されます。

橋梁の追加

ガント表示時、ツールバーの「＋橋梁を追加」ボタンから橋梁を追加できます。橋梁名・整理番号・径間数・点検完了日を入力します。追加した橋梁は一覧の末尾に追加されます。

点検完了日フラグ（🚩）

橋梁に点検完了日が設定されている場合、ガントチャート上の該当日付に赤いフラグ（🚩）が表示されます。工程割り振りの基準日として活用できます。

ヒント： ガントバーをドラッグ（左右に引っ張る）すると、日程をそのままずらせます。詳細な編集はバーをクリックしてモーダルから行います。

工程割り振りバーの見方

表示説明
橋梁名 📋自動割り振りで登録された工程。工程種別（調書作成・チェック等）の色で表示されます。
橋梁名 ✏自動割り振り後に手動で日程を修正したバーです。

3-2. リスト表示

「リスト」タブに切り替えると、橋梁ごとの工程を表形式で一覧できます。整理番号・担当者・ステータスなどで絞り込み検索が可能です。

ステータスバッジの見方

未着手 作業中 完了 遅延

遅延は「完了予定日を過ぎても完了日が未入力」の場合に自動で表示されます。

3-3. 工程の登録・編集・削除

工程を新規登録する

  1. ガントチャートの空白部分をクリックします。
  2. 「工程を追加」モーダルが開きます。工程種別・担当者・期間を入力します。
  3. 担当者は複数選択できます（チェックボックスで選択）。
  4. 「保存」ボタンをクリックして登録します。

工程を編集する

  1. ガントバーをクリックして編集モーダルを開きます。
  2. 担当者・開始日・完了予定日・完了日・メモを変更できます。
  3. 「保存」をクリックして反映します。

工程を削除する

  1. ガントバーをクリックして編集モーダルを開きます。
  2. モーダル内の「削除」ボタンをクリックします。
  3. 「本当に削除する」ボタンが表示されるので、再度クリックして確定します（2段階確認）。
注意： 削除した工程はもとに戻せません。誤操作に注意してください。
STAFF

担当者稼働

担当者ごとの当月から3ヶ月分のスケジュールをガントチャートで確認できます。特定日の空き状況確認、担当者の絞り込み表示、直接の予定追加が可能です。

担当者稼働ガントの構成
要素説明
担当者名（左端固定）横スクロール時も担当者名は左端に固定表示されます。
月・日ヘッダー（上部固定）縦スクロール時も上部に固定されます。
緑色の行空き確認日に予定が入っていない担当者は行が緑色にハイライトされます。
スクロールバーガント下部に常時表示されます。

4-1. 空き状況の確認

  1. 「空き確認日」の日付入力欄に確認したい日付を入力します。
  2. その日に予定が入っていない担当者の行が緑色でハイライトされ「✅ 空き」と表示されます。
  3. 「クリア」ボタンでハイライトを解除できます。

4-2. 担当者の絞り込み

ツールバーの「担当者」ボタンをクリックすると、表示する担当者を絞り込めます。

  1. 「担当者」ボタンをクリックしてドロップダウンを開きます。
  2. 表示したい担当者のチェックボックスをオンにします（複数選択可）。
  3. 選択中はボタンが紫色になり、選択人数が表示されます（例：「担当者（3名）」）。
  4. 「クリア」をクリックすると全員表示に戻ります。

4-3. 予定の追加

  1. 追加したい担当者の行のガントエリアをクリックします（クリックした位置が開始日になります）。
  2. 「予定を追加」モーダルが開きます。業務・橋梁・工程種別・期間を設定します。
  3. 「保存」をクリックして登録します。
ヒント： ガントバーに表示されている「📋 橋梁名」は工程割り振りで自動割り当てられたバーです。「✏」が付いているものは手動で修正済みです。
AUTO-ASSIGN

工程割り振り

担当者のシフト（出勤日・勤務時間）と橋梁ごとの必要時間をもとに、点検完了日から工程スケジュールを自動生成します。調書作成・チェック・修正の工程を連続して割り振ることができます。

5-1. 工程別担当者設定

  1. 左側の業務リストから対象業務を選択します。
  2. 「工程別担当者設定」パネルで、各工程のチェックボックスをONにして担当者を選択します。
  3. 担当者は工程ごとに個別に設定できます（調書作成・チェック・修正それぞれ別の担当者を指定可能）。
  4. 「担当者設定を保存」ボタンをクリックして保存します。
工程のチェーン（連続割り振り）
  • 調書作成：点検完了日の翌日から割り振られます。
  • チェック：調書作成の終了日の翌日から割り振られます。
  • 修正：チェックの終了日の翌日から割り振られます。

5-2. 自動割り振り実行

  1. 「橋梁・点検完了日」テーブルで各橋梁の点検完了日を入力します。テーブルには有効化した工程ごとの必要時間が表示されます。
  2. 「🔄 自動割り振り実行」ボタンをクリックします。
  3. 確認ダイアログで工程と担当者を確認して「OK」をクリックします。
  4. 実行中はボタンが「実行中…」と表示され、完了まで操作できません。完了後、実行前に選択していた業務が自動的に再選択されます。
割り振りのルール
  • 担当者のシフト設定（出勤曜日・1日の勤務時間）をもとに空き日程を検索します。
  • 必要時間は「径間係数設定」で登録した値を使用します。未登録の場合は 径間数 × 係数 × 8時間 で自動計算します。
  • 点検完了日が入力されていない橋梁はスキップされます。
  • 再実行すると、前回の割り振り結果はすべて削除されてから新たに登録されます。
注意： 再実行すると当該業務の既存割り当てがすべて削除されます。手動修正した内容も消えますのでご注意ください。

5-3. ガントで確認・調整

割り振り結果は画面下部のガントチャートで確認できます。

バーを手動で移動する

ガントバーをドラッグすると日程をずらせます。手動修正したバーには「✏️」が付きます。

日程を細かく編集する

バーをクリックすると編集ダイアログが開き、開始日・終了日を直接入力できます。

5-4. 担当者の工程を連動移動する

特定の担当者が担当する工程をまとめて前後にずらすことができます。

  1. 担当者フィルターで対象の担当者を選択します。
  2. 「📅 ○○ の工程を連動移動」ボタンをクリックします。
  3. 移動日数を入力します（プラス値で後倒し、マイナス値で前倒し）。
  4. 「実行」をクリックします。実行中はボタンが「実行中…」と表示されます。
  5. 完了後、実行前に選択していた業務が自動的に再選択されます。
ヒント： 連動移動は点検完了日の翌日より前には移動できません。制約を超えた場合は警告が表示されます。

各種設定

6-1. マスタ管理・CSV

担当者・業務（プロジェクト）・橋梁・工程種別の登録・編集・削除を行います。

タブ管理できる内容
担当者 氏名・表示色（ガントバーの色）・種別を登録します。
業務（プロジェクト） 業務名・発注者・期限を登録します。業務に紐付く橋梁もここから管理できます。
工程種別 工程の名称・表示色・並び順を設定します。
CSVインポート 橋梁データ・径間係数・必要時間・工程進捗データをCSVで一括登録・更新します。
橋梁の追加方法： ダッシュボードのガント表示時にツールバーの「＋橋梁を追加」ボタンから登録できます。または、マスタ管理の「業務（プロジェクト）」タブで対象業務を展開し、橋梁を追加することもできます。

「CSVインポート」タブの「工程進捗CSV」セクションから、各橋梁の工程担当者・期間・ステータスを一括登録・更新できます。既存の工程（iteration=1）は上書き更新されます。

ヒント： まずダウンロードして現在の登録内容を確認し、必要な列を編集してからインポートすると効率的です。既存データは上書き更新されます。

6-2. シフト設定

担当者ごとの勤務スケジュールを設定します。自動割り振りの計算に使用されます。

  1. 担当者名をクリックして設定パネルを開きます。
  2. 出勤曜日をボタンで選択します（青 = 出勤、白 = 休み）。
  3. 1日の標準勤務時間を入力します。
  4. 適用開始日を設定します。
  5. 「シフトを保存」をクリックして確定します。

特定日だけ変更する（個別変更）

シフト設定パネル下部の「個別勤務時間変更」から、特定日のみ勤務時間を上書きできます。勤務時間を「0」にすると休みとして扱われます。

6-3. 径間係数設定

橋梁ごと・工程ごとの径間係数と必要時間を設定します。自動割り振りの必要時間計算に使われます。

必要時間の計算式

必要時間 = 径間数 × 径間係数（時間/径間）

例）径間数4 × 係数4時間 = 16時間（2人日）
「必要時間」欄に直接入力した場合はその値が優先されます。空欄の場合は自動算出。

工程タブの切り替え

画面上部のタブ（調書作成 / チェック / 修正）で工程を切り替えて、工程ごとに設定できます。

  1. 工程タブ（調書作成・チェック・修正）を選択します。
  2. 業務名をクリックしてアコーディオンを開きます。
  3. 橋梁ごとに径間数・径間係数・必要時間を入力します。
  4. 「一括自動算出」ボタンで全橋梁の必要時間を一括計算できます。
  5. 「一括保存」ボタンで変更のある全橋梁をまとめて保存します。または各行の「保存」ボタンで個別に保存します。
ヒント： 未保存の変更がある場合、業務名ヘッダーに「● 未保存あり」と表示されます。「一括保存」ボタンを使うと効率よく保存できます。

6-4. システム設定

設定項目説明
径間係数のデフォルト値 径間係数が未設定の橋梁に適用される初期値です。変更すると全体の基準が変わります。
年度開始月 自動割り振りの対象期間を決める年度の開始月です。通常は4月（4）を設定します。
